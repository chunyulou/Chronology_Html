# 正覺大事記 - 使用說明

## 📁 檔案說明
| 檔案 | 說明 |
| --- | --- |
| `event-table.html` | 主網頁（純前端，可直接開啟或放上 GitHub Pages） |
| `table_data.js` | 大事紀資料（196 則，序號／日期／大事／紀要，順序與內容同來源 Word 檔） |
| `proposals_data.js` | 六份分頁籤提案的分類定義，以及 196 則大事在各提案中的歸類 |
| `publications_data.js` | 出版品目錄 |

## 🚀 使用方式
1. 四個檔案放在同一目錄下
2. 用瀏覽器開啟 `event-table.html`（或部署到 GitHub Pages）

## ✨ 功能

### 1. 六份分頁籤提案，按鈕切換
最上方的「分頁籤提案」列可切換八種檢視（提案順序依 0809 彙整檔）：

| 按鈕 | 分頁籤 |
| --- | --- |
| 雅鴦菩薩提案 | 組織發展／對外弘法／共修紀事／摧邪顯正／公益推廣／出版流通／綜合紀事 |
| 柄富菩薩提案 | 平實導師／組織發展／講經弘法／摧邪顯正／出版流通／社會服務 |
| 英妙滿菩薩們的提案 | 平實導師／講經開課與禪修／法會與弘法／組織與據點／摧邪顯正／社會公益推廣／出版流通管理 |
| 劍華菩薩提案 | 組織發展／對外弘法／共修紀事／摧邪顯正／公益推廣／出版流通／綜合紀事 |
| 麗薇菩薩提案 | 組織沿革／弘法講經／共修紀事／摧邪顯正／公益推廣／出版流通／綜合紀事 |
| 淳渝提案 | 平實導師弘法／書刊媒體／共修/禪修/法會／組織發展／摧邪顯正／推廣與公益 |
| 現場版 | 預設以「半數以上（3 案以上）採用」的標籤歸類，並即時反映現場操作欄的調整 |
| 各案比對＋現場操作 | 六案並排比對與標籤編輯（見下） |

每個提案切換後：
- 提案說明列顯示該提案的**整體分類依據**
- 每個分頁籤開頭的說明欄顯示**該分類的收錄／不收錄原則**
- 總表恆為 196 則，依原始序號、日期與大事紀要順序呈現，文字不做任何更動
- **總表的分類標籤可點擊**，直接跳到該分頁籤並定位、閃示同一則大事
  （月英淑妙淑滿提案之建議事項：「在總表頁籤的各則事件，用超連結連到後面分頁籤，以方便前後查看運用」）

各案的歸類**完全照錄 0809 彙整檔**：

- 逐則分類取自彙整檔「大事」工作表（六個提案欄）；**大事、日期、紀要、序號一律不動**
- 分頁籤名稱、順序與說明取自「分類」工作表，**一字未改；規則欄空白者網頁上即留白，不做任何補述**
- 原檔中使用舊名稱之處**照原文顯示**（雅鴦 5 處、劍華 2 處「共修活動」；劍華 2 處「破邪顯正」），
  標籤後方以 `≡共修紀事`、`≡摧邪顯正` 小字標示
- **計票與歸類時視為同一分類**：共修活動＝共修紀事、摧邪顯正＝破邪顯正，
  因此不會有大事因舊名稱而漏出分頁籤（對照表定義於 `proposals_data.js` 的 `tagAliases`）
- 「整體分類依據」欄位：柄富、英妙滿兩案取自其原始提案文件並註明出處；
  其餘各案原檔無此段，僅標示資料來源，不代擬內容

### 2. 各案比對＋現場操作
- 版面為 **1 欄大事 ＋ 7 欄**：六個提案各一欄，最右為現場操作（欄數與欄寬依提案數自動調整）
- 每一則大事並排顯示各案的分類標籤
- 標籤依**採用案數**分三級標示，一眼看出誰與誰一致：
  - **六案一致**：一般灰色（共 9 則）
  - **達 3 案以上**：橘色
  - **未達 3 案**：紅字＋螢光底＋底線
- 列首另有紅色標記與「分類有差異」徽章（共 187 則各案不完全一致）
- 可勾選「只顯示各案分類有差異者」或「只顯示待決定」快速鎖定討論標的
- 最右欄「現場操作」**預設帶入半數以上（3 案以上）採用的標籤**：
  - **158 則**有共識可循，直接預設歸類（虛線綠標＝預設值）
  - **38 則**未達半數共識，標為橘色「各案分歧．待決定」
  - 點「編輯」可複選（各案分頁籤已彙整為唯一清單共 21 個，並標示哪幾案採用），或手動輸入自訂分類文字
- 編輯結果**即時同步**到「現場版」分頁籤與統計列

> 共識門檻取「半數以上」：六案下 ≥2 票只剩 3 則待決定（過寬）、≥4 票有 99 則待決定（過嚴），故取 ≥3 票。

### 2-1. 現場分類即時統計（08/10 會議用）
比對表上方的綠色統計列會**隨每一次編輯即時重算**：

- 每個分類一顆計數膠囊（點擊可直接跳到「現場版」的該分頁籤）
- 橘色「待決定」膠囊顯示尚未歸類的則數，點擊即篩出這些大事
- 右側總計：已歸類 N / 196 則 ｜ 分類數 ｜ 標籤總數 ｜ 現場確認則數
- 另外**每個分頁籤按鈕上都有筆數徽章**，六個提案與現場版皆適用


### 3. 存檔與防遺失（GitHub Pages 純前端可行）
GitHub Pages 為靜態託管、沒有後端，因此採用瀏覽器端存檔並加上多層保護：

- **即時自動存檔**：每按一次勾選／取消／新增標籤就立刻寫入 `localStorage`。**重整、當掉、關分頁、關瀏覽器都不會遺失**
- **存檔狀態列**：工具列顯示「✓ 已自動儲存 HH:MM:SS（N 則）．尚未匯出」；若瀏覽器無法存檔會轉為紅色警示
- **復原上一步**：保留最近 30 次變更，誤點、誤刪、甚至誤按「清除現場調整」都能救回
- **離開前提醒**：有未匯出的異動時，重整或關閉分頁會跳出瀏覽器確認
- **無痕視窗警告**：偵測到無法存檔（無痕／私密視窗、停用網站資料）時，頁面上方顯示黃色警告橫幅
- **備份 JSON / 還原 JSON**：把現場調整存成檔案帶走，或在別台電腦、別的瀏覽器還原
  （此 JSON 同時就是交付給正式官網的資料檔，格式見下）

**仍然會遺失的情況**（請以「備份 JSON」或匯出 Excel／Word 因應）：
1. 換一台電腦、換一個瀏覽器、或用無痕視窗
2. 清除瀏覽器的「Cookie 和網站資料」
3. 換網址開啟（`localStorage` 綁定網域；用 `file://` 開啟本機檔案與 GitHub Pages 網址各自獨立）

**建議做法**：討論結束前一定按一次「匯出 Excel」或「備份 JSON」，狀態列會變成「已自動儲存並已匯出」。

### 4. 一鍵匯出
- **匯出 Excel（總表＋標籤）**：`.xls`，欄位為 序號／日期／大事／紀要／現場標籤／各提案（依提案數自動增減）／各案是否一致
- **匯出 Word（各分頁籤）**：一次產生**多個獨立的 `.doc` 檔**，全部依總表原始順序
  - `正覺大事紀_總表_YYYYMMDD.doc`：欄位由左到右為 序號／日期／大事／紀要／分頁籤
  - `正覺大事紀_<分頁籤名>_YYYYMMDD.doc`：每個分頁籤各一檔，欄位為 序號／日期／大事／紀要
  - 版面完全比照 `正覺大事紀第1版-各部部長(20260626).docx`：A4 橫向、上下 1.5cm 左右 1cm、
    微軟正黑體 12pt、行距固定 15pt、欄寬 1.75/3.0/8.0/15.0cm、表頭 #CAEDFB 粗體且跨頁重複
  - 瀏覽器若詢問「是否允許下載多個檔案」請按「允許」

### 5. 交付給正式官網（Joomla）的 JSON

「備份 JSON」產生的檔案同時就是交付檔，**大事一律依序號排序**：

```jsonc
{
  "version": 3,
  "匯出時間": "...",
  "資料來源": "大事紀1150630.xlsx",
  "說明": "「大事」與「紀要」文字不得更動；分頁籤依大事序號歸類；超連結請套用於「大事」欄中的對應文字。",
  "分頁籤": [ { "名稱": "講經開課與禪修", "大事序號": [6, 7, 8, 10, ...] } ],
  "大事": [
    {
      "序號": 1,
      "日期": "1987",
      "大事": "平實導師自成無相念佛之法",
      "紀要": "平實導師1944年出生於彰化……",
      "超連結": [ { "文字": "導師", "網址": "https://www.enlighten.org.tw/master-pingsxiao" } ],
      "分頁籤": ["平實導師"],
      "各案分類": { "雅鴦菩薩提案": [...], "柄富菩薩提案": [...], "英妙滿菩薩們的提案": [...], "劍華菩薩提案": [...], "麗薇菩薩提案": [...], "淳渝提案": [...] },
      "現場已確認": false
    }
  ],
  "還原用": { "tags": { ... }, "customPool": [ ... ] }
}
```

- `分頁籤` 陣列可直接用來建立官網的頁籤與各頁籤的大事清單
- `超連結` 的「文字」是要在「大事」欄中加上連結的字串
- `還原用` 供本網頁的「還原 JSON」使用，官網不需理會

### 6. 其他
- 日期欄可切換升冪／降冪
- 大事欄可搜尋（同時比對大事與紀要，命中以螢光標記）
- 「紀要」按鈕開啟詳細說明視窗
- 出版流通頁籤附「出版品目錄」子頁
- 響應式版面，支援手機
- **手機版（≤768px）提案列可展開／收合**：預設收合為一列，鈕面顯示目前檢視的提案名稱；
  點一下展開全部 8 個選項，選定後自動收起，避免提案列佔掉表格高度
