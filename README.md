# 正覺大事記 - 使用說明

## 📁 檔案說明
| 檔案 | 說明 |
| --- | --- |
| `event-table.html` | 主網頁（純前端，可直接開啟或放上 GitHub Pages） |
| `table_data.js` | 大事紀資料（196 則，序號／日期／大事／紀要，順序與內容同來源 Word 檔） |
| `proposals_data.js` | 三份分頁籤提案的分類定義，以及 196 則大事在各提案中的歸類 |
| `publications_data.js` | 出版品目錄 |

## 🚀 使用方式
1. 四個檔案放在同一目錄下
2. 用瀏覽器開啟 `event-table.html`（或部署到 GitHub Pages）

## ✨ 功能

### 1. 三份分頁籤提案，按鈕切換
最上方的「分頁籤提案」列可切換五種檢視：

| 按鈕 | 內容 |
| --- | --- |
| 淳渝提案 | 講經開課與禪修／法會與弘法／弘法據點／摧邪顯正／社會公益推廣／出版流通 |
| 柄富提案 | 平實導師／組織發展／講經弘法／摧邪顯正／出版流通／社會服務 |
| 月英淑妙淑滿提案 | 講經開課與禪修／法會與弘法／組織與據點／摧邪顯正／社會公益推廣／出版流通與管理（＋建議增列「平實導師」） |
| 現場版 | 預設以「多數提案採用」的標籤歸類，並即時反映現場操作欄的調整 |
| 三案比對＋現場操作 | 三案並排比對與標籤編輯（見下） |

每個提案切換後：
- 提案說明列顯示該提案的**整體分類依據**
- 每個分頁籤開頭的說明欄顯示**該分類的收錄／不收錄原則**
- 總表恆為 196 則，依原始序號、日期與大事紀要順序呈現，文字不做任何更動

三案的歸類**完全依照各自提案原文**：
- 淳渝提案：依其六個頁籤的收錄／不收錄原則，且原文所舉之大事一律歸入原文指定的頁籤（例：電視弘法→法會與弘法；舍利安奉→弘法據點）
- 柄富提案：原文明列前五十筆之歸屬，該五十筆完全照原文序號歸類；其餘依其頁籤原則
- 月英淑妙淑滿提案：依〈分頁籤與各部主標對照表〉，A05＝兩會（歸「組織與據點」）；頁籤說明同時保留原六個分頁籤的收錄原則

### 2. 三案比對＋現場操作
- 版面為 **1 欄大事 ＋ 4 欄**：淳渝／柄富／月英淑妙淑滿／現場操作
- 每一則大事並排顯示三案的分類標籤
- 標籤依**採用案數**分三級標示，一眼看出誰與誰一致：
  - **三案一致**：一般灰色
  - **兩案一致**：橘色（例如淳渝與柄富同為「出版流通」，月英淑妙淑滿為「出版流通與管理」）
  - **僅單案採用**：紅字＋螢光底＋底線
- 列首另有紅色標記與「分類有差異」徽章
- 可勾選「只顯示三案分類有差異者」快速檢視爭議項
- 最右欄「現場操作」**預設帶入「多數提案採用」的標籤**（三案中至少兩案採用者）：
  - 153 則有多數可循，直接預設歸類（虛線綠標＝預設值）
  - 43 則三案各不相同、無多數可循，標為橘色「三案分歧．待決定」
  - 點「編輯」可多選三案的任一標籤，或手動輸入自訂分類文字
  - 經現場確認者轉為實線綠標
- 編輯結果**即時同步**到「現場版」分頁籤

### 3. 存檔與防遺失（GitHub Pages 純前端可行）
GitHub Pages 為靜態託管、沒有後端，因此採用瀏覽器端存檔並加上多層保護：

- **即時自動存檔**：每按一次勾選／取消／新增標籤就立刻寫入 `localStorage`。**重整、當掉、關分頁、關瀏覽器都不會遺失**
- **存檔狀態列**：工具列顯示「✓ 已自動儲存 HH:MM:SS（N 則）．尚未匯出」；若瀏覽器無法存檔會轉為紅色警示
- **復原上一步**：保留最近 30 次變更，誤點、誤刪、甚至誤按「清除現場調整」都能救回
- **離開前提醒**：有未匯出的異動時，重整或關閉分頁會跳出瀏覽器確認
- **無痕視窗警告**：偵測到無法存檔（無痕／私密視窗、停用網站資料）時，頁面上方顯示黃色警告橫幅
- **備份 JSON / 還原 JSON**：把現場調整存成檔案帶走，或在別台電腦、別的瀏覽器還原

**仍然會遺失的情況**（請以「備份 JSON」或匯出 Excel／Word 因應）：
1. 換一台電腦、換一個瀏覽器、或用無痕視窗
2. 清除瀏覽器的「Cookie 和網站資料」
3. 換網址開啟（`localStorage` 綁定網域；用 `file://` 開啟本機檔案與 GitHub Pages 網址各自獨立）

**建議做法**：討論結束前一定按一次「匯出 Excel」或「備份 JSON」，狀態列會變成「已自動儲存並已匯出」。

### 4. 一鍵匯出
- **匯出 Excel（總表＋標籤）**：`.xls`，欄位為 序號／日期／大事／紀要／現場標籤／淳渝提案／柄富提案／月英淑妙淑滿提案／三案是否一致
- **匯出 Word（各分頁籤）**：`.doc`，先是總表（含標籤欄），其後每個現場分頁籤各一個表格，欄位比照來源 Word 檔的 序號／日期／大事／紀要

### 5. 其他
- 日期欄可切換升冪／降冪
- 大事欄可搜尋（同時比對大事與紀要，命中以螢光標記）
- 「紀要」按鈕開啟詳細說明視窗
- 出版流通頁籤附「出版品目錄」子頁
- 響應式版面，支援手機

## 🔧 技術說明
- 純 HTML + CSS + JavaScript，無框架、無外部相依
- 資料與邏輯分離；分類全部集中在 `proposals_data.js`，修改分類不需動 HTML
- 匯出以 Blob 產生 Excel／Word 相容的 HTML，不需任何套件

## 💡 注意事項
1. 四個檔案請放在一起，否則資料無法載入
2. 現場調整存在瀏覽器本機，換瀏覽器／換電腦／清除瀏覽資料都會不見，重要成果請用「備份 JSON」或直接匯出
3. 建議使用 Chrome、Firefox、Edge 等現代瀏覽器
